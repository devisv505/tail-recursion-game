# Screenshots

Drop PNGs here using exactly these names. Any that are missing render as a
labelled placeholder on the page rather than a broken image, so you can add
them one at a time.

| File | What it should show |
|---|---|
| `title.png` | The title screen, with the wordmark and the menu. |
| `level-select.png` | The puzzle grid — the 100 numbered squares. |
| `straight-shot.png` | Puzzle 1, Straight Shot: the map plus the two-block program. |
| `zigzag.png` | Zigzag, with the Repeat N Times chain visible. |
| `perimeter.png` | Perimeter, with Wall Ahead? branching to Turn Right and Move Forward. |
| `inspector.png` | A run in progress with the program inspector panel open (`tab`). |

`title.png` is also the social preview image (`og:image`), so make that one a
clean full-window shot.

To change the list, captions, or order, edit `screenshots` in
[`assets/js/config.js`](../js/config.js) — the gallery is generated from it.

## Capturing them

Run the game, press `tab` if you want the inspector in shot, and take a
full-window capture (`Win`+`Shift`+`S` on Windows, `Cmd`+`Shift`+`4` then space
on macOS). 16:9 crops best — the gallery frames are that ratio and will
centre-crop anything else.
